# Prompt Drill Pack

## Drill 1: Add Context

Rewrite the prompt to include audience, decision, source material, and desired output.

## Drill 2: Add Constraints

State exclusions, boundaries, tone, length, and unacceptable assumptions.

## Drill 3: Add Evidence

Require source references, confidence levels, and uncertainty flags.

## Drill 4: Add Validation

Ask for checks, failure modes, missing information, and review steps before final output.
