Suggested sequence

Put the guidance into practice

  1. Set the execution boundary Create the packet for one workflow and define the outcome, owner, receiver, and transfer boundary.
  2. Capture Draft and Ground evidence Record the request, scope, sources, assumptions, AI role, and initial output.
  3. Validate and approve Record checks, corrections, unresolved items, approval authority, and release conditions.
  4. Handoff and learn Test receiver acceptance, record escalation, and capture exceptions, correction load, and reassessment.
  5. Deliverable source definition and learner instructions
  6. Deliverable fillable Learn worksheet or packet
  7. Deliverable worked example
  8. Deliverable validation checklist

When this stage is complete

  • purpose and scope understood
  • all Learn fields completed
  • worked example included
  • result validated against the source or transfer test
  • next action and owner recorded
